# Street Performance – Website

Statische HTML/CSS/JavaScript-Website. Die Startseite ist `index.html`, weitere Dateien: `style.css`, `script.js`, `quote.html`.

## Live-Website

Nach GitHub Pages-Aktivierung unter **Settings → Pages → Deploy from a branch → main → / (root)** wird die Website über `https://z4vv9v9yrb-blip.github.io/street-performance-website/` veröffentlicht.

Hinweis: Das Startbild ist derzeit von Instagram extern eingebunden; dieser Bildlink kann ablaufen. Die Inhalte enthalten noch Demotexte und Kontakt-Platzhalter. Das Kontaktformular öffnet ein E-Mail-Programm; es gibt keinen eigenen Formularserver.

Änderungen an Dateien auf dem `main`-Branch werden nach Aktivierung von GitHub Pages automatisch veröffentlicht.
